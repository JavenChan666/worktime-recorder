# 工时记录助手

纯本地离线的工时记账应用，面向打工人、临时工、技术工、多岗位兼职人群。
记工时、自动算工资、按月统计、导出对账，**全程不联网、不上传任何数据**。

- 🌐 网页版 / PWA：可直接添加到手机桌面
- 📱 安卓 APK：`工时记录助手-v1.0.apk`（2.8 MB，无任何权限申请）

## 功能

| 模块 | 内容 |
|---|---|
| 首页 | 当月总收入 / 出勤天数 / 总有效工时 / 总加班 / 日均工时，每日工时柱状图 |
| 工时录入 | 上下班时间、休息扣除、4 种工作类型（正常班/平日加班/周末加班/夜班）、备注 |
| 自动结算 | 总在岗时长、有效工时、正常/加班拆分、当日工资实时预览 |
| 日历 | 按月查看每日工时，点日期查看当天明细 |
| 记录管理 | 编辑、删除、按日期/备注/类型搜索、按月筛选 |
| 薪资配置 | 时薪、平日 1.5 / 周末 2.0 倍率、夜班补贴（按天/按时）、休息时长、标准工时 |
| 数据安全 | 本地保存、JSON 备份与恢复（覆盖/合并） |
| 导出 | Excel（.xlsx）/ CSV 对账文件，可分享给老板 / 人事 |
| 平板适配 | 横屏自动切换左侧导航 + 表格大视图 |

## 计算规则

```
总在岗时长 = 下班 − 上班              // 跨零点自动 +24h
有效工时   = 总在岗 − 休息扣除         // 默认精确到 0.5h
有效 ≤ 标准工时(8h) → 正常 = 有效，加班 = 0
有效 > 标准工时     → 正常 = 8h，  加班 = 有效 − 8h
日工资 = 正常×时薪 + 加班×时薪×倍率 + 夜班补贴
```

周末加班按行业惯例对当日全部有效工时乘 2 倍。修改配置后自动重算全部历史记录。

## 技术栈

原生 HTML + CSS + JavaScript，**零第三方依赖、无需构建、无联网请求**。
APK 使用 Capacitor 封装，`AndroidManifest.xml` 中不含 INTERNET 权限。

Excel 导出为手写实现：自行计算 CRC32 并拼装 ZIP 与 SpreadsheetML，不依赖 SheetJS，保证完全离线。

## 数据存储

数据保存在设备本地（WebView / 浏览器的 localStorage），对应需求文档的三张表：

- `salary_config` —— 全局薪资配置（id=1）
- `work_record` —— 工时主记录
- `work_month_stat` —— 月度统计（首页秒加载）

> ⚠️ 清除浏览器数据或卸载应用会丢失记录，换机前请在「数据」页导出 JSON 备份。
